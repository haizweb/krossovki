# NEONSOLE — sneaker concept store

Адаптивный концептуальный магазин кроссовок на чистом HTML, CSS и JavaScript.

## Возможности
- Адаптивная вёрстка для ПК, планшета и телефона.
- Каталог из 8 демонстрационных моделей.
- Поиск, фильтры по категориям, сортировка.
- Быстрый просмотр товара, описание и выбор размера.
- Корзина: количество, удаление, сумма и порог бесплатной доставки.
- Избранное.
- Демо-оформление заказа без реальной оплаты.
- Форма подписки с сохранением в localStorage.
- Анимации, эффекты при наведении, бегущая строка, появление блоков.
- Сохранение корзины и избранного между перезагрузками.

## Локальный запуск
Распакуй архив и открой `index.html` в браузере. Для разработки можно использовать VS Code + расширение Live Server.

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub, например `neonsole-store`.
2. Загрузи в корень репозитория файлы `index.html`, `styles.css`, `app.js`, `README.md`.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Через минуту-две ссылка появится в разделе Pages: `https://ТВОЙ-USERNAME.github.io/neonsole-store/`.

## Важно
Это портфолио-концепт. Оплата, реальный склад, отправка писем и серверная база не подключены. Заказ только показывает демо-подтверждение, а данные формы не отправляются на сервер. Изображения загружаются с Unsplash, шрифт — с Google Fonts, поэтому для них нужен интернет. Для коммерческого запуска подключи сервер/API, платёжный сервис, политику конфиденциальности и изображения с подходящими правами.


## Обновление Dark Edition

- Каталог расширен до 16 моделей обуви.
- Более крупная типографика, глубокие тёмные тона и обновлённые карточки товаров.
- Корзина показывает количество, размер, стоимость товаров, стоимость доставки и прогресс до бесплатной доставки.
- Отзывы отправляются через форму и сохраняются в `localStorage` этого браузера. Вымышленные оценки и отзывы не подставляются. Для общего публичного списка отзывов между всеми посетителями понадобится серверная база данных и API.
